Let us work through this problem, which was presented in AIEEE 2003 and focuses on finding the minimum value of a function. The question states that for a real number $ x $, when it is added to its reciprocal, the sum reaches its minimum value. We are asked to find the value of $ x $.

Let the given number be $ x $. This means we are adding $ \frac{1}{x} $ to $ x $. Let us denote this sum as $ f(x) $. Therefore, $ f(x) = x + \frac{1}{x} $.

To find the minimum value of this function, we take its derivative and set it equal to zero. The first derivative is given by:

$$
f'(x) = 1 - \frac{1}{x^2}
$$

Setting $ f'(x) = 0 $, we get:

$$
1 - \frac{1}{x^2} = 0
$$

This simplifies to:

$$
\frac{1}{x^2} = 1
$$

Which implies:

$$
x^2 = 1 \Rightarrow x = \pm 1
$$

Next, we determine whether these points correspond to a minimum or maximum by examining the second derivative. The second derivative is:

$$
f''(x) = \frac{2}{x^3}
$$

Evaluating this at $ x = 1 $:

$$
f''(1) = \frac{2}{1^3} = 2 > 0
$$

This indicates that the function has a minimum at $ x = 1 $.

Now, evaluating the second derivative at $ x = -1 $:

$$
f''(-1) = \frac{2}{(-1)^3} = \frac{2}{-1} = -2 < 0
$$

This shows that the function has a maximum at $ x = -1 $.

Therefore, the minimum value of the sum occurs when $ x = 1 $. Hence, the correct answer is $ x = 1 $.
