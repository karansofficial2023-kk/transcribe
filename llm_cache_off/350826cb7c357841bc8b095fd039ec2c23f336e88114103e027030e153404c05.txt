Welcome students to the NEET 2019 question and answer solutions. Let's now work through question number 176, which asks: Which of the following is a commercial blood cholesterol-lowering agent? The options provided are cyclosporine A, statin, streptokinase, and lipases. This question relies entirely on memory. If you cannot recall the correct commercial agent for lowering blood cholesterol, it will be difficult to answer this question correctly. However, if you remember the information, this is a straightforward question. The correct answer is statin, as it is widely used as a commercial medication to lower blood cholesterol levels.
